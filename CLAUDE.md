# CLAUDE.md

## Development workflow

- Every change starts with its own GitHub issue (`gh issue create`).
- Work on a separate branch per issue, cut from `main`.
- Branch name starts with the issue number: `<issue>-short-description` (e.g. `29-loan-calculator`).
- Commit messages start with the issue number: `#<issue> Short description` (e.g. `#29 Add bank loan calculator`).
- Always ask before committing or pushing. Never commit or push without explicit approval.
